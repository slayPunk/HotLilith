# HotLilith 0.2: холст в Hyprland

HotLilith переносит механику Lilith в существующую сессию Hyprland 0.57.0: окна остаются настоящими приложениями, их можно отдалять, двигать по свободному пространству и возвращать в исходный тайлинг. Для работы достаточно одного экрана. Панель, лаунчер, уведомления и блокировка остаются за выбранной оболочкой рабочего стола. Serpantinum не требуется.

## Основные действия

Модуль настроек не назначает хоткеи. Таблица описывает отдельно подключаемый `config/bindings.example.lua`; выберите свободные сочетания перед подключением.

| Действие | Управление |
|---|---|
| Тайлинг ↔ холст | `Super+G` |
| Холст текущего стола ↔ общий холст | `Super+Ctrl+G` |
| Аварийный выход | `Super+Ctrl+Shift+G` |
| Схватить и сдвинуть пространство | ЛКМ на пустом фоне или средняя кнопка |
| Изменить масштаб около указателя | Колесо на пустом фоне; `Ctrl+колесо` или `Super+колесо` над окном |
| Переместить / растянуть окно | `Super+ЛКМ` / `Super+ПКМ` |
| Переместить камеру с клавиатуры | `Super+Alt+стрелки` |
| Выбрать соседнее окно на холсте | `Super+Ctrl+Alt+стрелки` |
| Вместить все окна | `Super+Z` |
| Обзор ↔ 100% | `Super+Alt+G` |
| Вернуться в начало холста, 100% | `Super+Ctrl+Home` |
| Центрировать активное окно | `Super+Ctrl+C` |
| Заранее выделить область для следующего окна | `Super+Ctrl+N` |
| Освободить захваченную игрой мышь | `Super+Ctrl+Escape` |
| Включить / выключить принудительный захват для старой игры | `Super+Ctrl+P` |
| Автоматически разместить ожидающее окно; иначе отменить область / остановить инерцию | `Escape` |

Быстрое движение с отпусканием кнопки бросает окно или камеру. Чтобы поставить точно, остановите указатель перед отпусканием. Новый захват, изменение масштаба, переход к окну и команда возврата домой останавливают инерцию. Магнитные направляющие показывают выравнивание с другими окнами и границами видимой области. Привязка действует и при изменении размера; ограничения размеров приложения имеют приоритет.

Каждое новое самостоятельное окно на активном холсте ждёт выделения области ЛКМ. До размещения оно не участвует в рендеринге и выборе окон. Если открывается несколько окон, они размещаются по очереди. `Escape` автоматически размещает текущее ожидающее окно и переводит к следующему. Закрытие приложения удаляет его из очереди. Ожидание не истекает по таймеру.

Диалоги, включая «Сохранить файл», открываются у своего родителя без отдельного выделения. Если родитель ещё ждёт размещения, диалог появляется вместе с ним после выбора области или Escape. Меню и другие protocol popups сохраняют обычную работу. Создание окна внутри активного drag-and-drop обрабатывается текущим DnD-путём, чтобы не прервать перенос.

Можно заранее нажать `Super+Ctrl+N` и нарисовать область перед запуском приложения. Она расходуется один раз и истекает через минуту, если приложение так и не открыто. Минимальная область — 80×60 единиц холста; ограничения размеров приложения имеют приоритет. Уже открытые окна при первом входе свободно раскладываются с промежутками.

## Память двух холстов

Позиции, размеры окон, камера и масштаб сохраняются отдельно для общего холста и каждого рабочего стола. Возврат в тайлинг восстанавливает native-состояние окон; сохранённые координаты холста при этом остаются доступны.

Файл памяти: `${XDG_STATE_HOME:-$HOME/.local/state}/hotlilit/canvas-memory-v2.txt`. Запись атомарная, права `0600`; файл содержит классы и заголовки окон. Сохранение происходит после короткой паузы в изменениях и перед обычным закрытием холста. При аварийном завершении последние изменения до записи могут потеряться.

Окна сопоставляются по приложению и заголовку; при первом наполнении после входа допускается свободное место того же приложения. Несколько окон получают разные записи. Приложения с меняющимися заголовками могут потребовать ручной расстановки. Максимум — 512 записей окон, старые вытесняются. Повреждённые и недопустимые записи пропускаются.

Для отключения памяти поменяйте `remember_layout = false` в своём экземпляре `canvas.lua`. Удаление файла при закрытой сессии сбрасывает память между запусками.

## Игры

Полноэкранная игра получает обычный рендеринг и ввод Hyprland; после выхода из fullscreen холст возвращается с прежней камерой и масштабом. Оконная игра может участвовать в масштабе и расстановке. Игровой захват указателя работает в уменьшенном окне: относительные движения мыши передаются в исходных единицах, поэтому масштаб холста не меняет чувствительность камеры. Положение удержания и область ограничения указателя переводятся в видимые координаты окна. Перемещение окна и жесты холста не должны поворачивать игровую камеру.

`Super+Ctrl+Escape` освобождает указатель. Щелчок по окну возвращает ему фокус; игра может запросить захват снова. Обычный `Escape` остаётся игровым действием, кроме активного выделения области или инерции холста.

Если старая игра получает относительные движения, но сама не запрашивает блокировку указателя, сфокусируйте её окно и нажмите `Super+Ctrl+P`. Этот режим удерживает указатель внутри видимого окна до повторного нажатия или `Super+Ctrl+Escape`. Он полезен, например, для некоторых игр в виртуальном рабочем столе Wine.

Испытания и ограничения конкретных игр описаны в [протоколе проверки](validation.md). Проверка одной игры не гарантирует совместимость со всеми движками, Proton, оверлеями и античитами.

## Предпросмотр и установка

Текущий модуль рассчитан на Hyprland 0.57.0, Lua-конфиг и dwindle без зависимости от Serpantinum. Требования к сборке — в [README на русском](../README.ru.md).

Из каталога проекта:

```bash
bash build.sh
python3 preview.py
```

Это отдельная тестовая сессия. Закройте её окно или нажмите внутри `Super+Shift+Escape`.

```bash
bash build.sh
python3 install.py
python3 install.py --enable
```

Первые две команды готовят файлы; `--enable` подключает настройки к текущему конфигу с резервной копией и не назначает хоткеи. Пример управления подключается отдельно вручную. Отключение: `python3 install.py --remove`.

После обновления Hyprland требуется совпадающая сборка плагина. Переустановка личного конфига может удалить подключение. Независимый модуль нужно подключать после основных настроек Hyprland; персональные адаптеры живут в своих dotfiles.

## Ограничения

- Это адаптация поведения Lilith поверх Hyprland. Группы окон сейчас отклоняются при входе в холст; сначала разгруппируйте их.
- При изменении состава окон сохраняется корректный тайлинг, но прежнее дерево разбиения не восстанавливается буквально.
- Дополнительные физические экраны, hotplug и смена драйвера требуют отдельных испытаний.
- Внутренние API Hyprland меняются; новой версии композитора может потребоваться исправление исходников плагина.

## Наследование темы

Публичный модуль сохраняет нативное оформление окон и наследует анимацию `windowsMove`. Палитра выделения и миникарты берётся из рамок Hyprland, изменения подхватываются после reload. Для интеграции с генераторами тем предусмотрены `canvas.accent` и `canvas.panel_color`; [пример и границы автоматического наследования](../README.md#appearance-follows-your-dotfiles). Двойная рамка остаётся опциональной.
